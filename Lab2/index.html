    Лабораторная работа №2: Django¶

    Информационная система туристического агентства¶

    О проекте¶

    Данный проект представляет собой информационную систему для туристического агентства, разработанную на фреймворке Django.

    Система предназначена для хранения информации о турах, регистрации пользователей, резервирования туров, написания отзывов и администрирования через Django-admin.

    Проект реализован как единый Django-проект tour_agency, внутри которого функционал разделён на три приложения:

    Приложение Назначение Документация
    users Регистрация и аутентификация пользователей, профиль users.md
    tours Управление турами, выездами, резервированиями, подтверждение через admin tours.md
    reviews Написание и хранение отзывов к турам reviews.md

    Цель работы¶

    Разработка информационной системы, обеспечивающей:

    • хранение информации о турах (название, турагентство, описание, период проведения, условия оплаты);
    • регистрацию новых пользователей;
    • просмотр и резервирование туров;
    • редактирование и удаление собственных резервирований;
    • написание отзывов к турам;
    • подтверждение резервирований администратором через Django-admin;
    • формирование клиентской таблицы всех проданных туров по странам.

    Архитектура проекта¶

    Проект построен по модульному принципу: вся логика разделена на три приложения, каждое из которых отвечает за свой участок функционала. Взаимодействие между приложениями происходит в рамках одного Django-проекта.

    Взаимодействие приложений¶

    • users — регистрация, вход, профиль, смена пароля; пользователь выступает владельцем резервирований и автором отзывов.
    • tours — хранит туры, выезды и резервирования; сотрудники управляют статусами заявок; формируется информация о проданных турах по странам.
    • reviews — хранит отзывы, привязанные к выездам (и через них — к турам) и к авторам.

    Модель данных (обзор)¶

    Модель Приложение Назначение
    User users Пользователь (наследник AbstractUser)
    Country tours Страна маршрута
    Tour tours Тур: название, страны, описание
    Departure tours Выезд: конкретные даты проведения тура
    Reservation tours Заявка пользователя на выезд со статусом
    Review reviews Отзыв: автор, выезд, оценка, текст, дата

    Подробное описание моделей — в документации соответствующих приложений.

    Реализованный функционал¶

    № Требование Реализация Статус
    1 Регистрация новых пользователей Приложение users: регистрация, вход, профиль, смена пароля ✅
    2 Просмотр и резервирование туров Приложение tours: список доступных туров, детальная страница, подача заявки на выезд ✅
    3 Редактирование и удаление своих резервирований Приложение tours: список текущих заявок, отзыв заявки ✅
    4 Написание отзывов (дата тура, текст, рейтинг, комментатор) Приложение reviews: модель Review, привязка к выезду (даты тура), автор, рейтинг, текст ✅
    5 Подтверждение резервирования через Django-admin Приложение tours: модели зарегистрированы в admin; смена статуса заявки также доступна staff на странице выезда ✅
    6 Таблица всех проданных туров по странам Приложение tours: агрегация подтверждённых заявок по странам тура ✅

    Разграничение доступа¶

    Роль Возможности
    Анонимный пользователь Регистрация, вход
    Авторизованный клиент Просмотр туров, подача и отзыв заявок, история поездок, написание отзывов, профиль
    Сотрудник (staff) Всё, что клиент + создание туров, добавление выездов, управление статусами заявок, доступ в Django-admin

    Разграничение реализовано через LoginRequiredMixin, StaffRequiredMixin (UserPassesTestMixin по is_staff) и проверки в шаблонах (user.is_staff).
